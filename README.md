## 目录与验证

- `tools/`：检查、构建及Windows诊断入口；硬件脚本不是普通预检。
- `handoff/2026-10-22/work/`：维护中的协议、渲染、平台适配与测试代码。目录日期是快照起点，不代表最新版本号。
- `handoff/2026-10-22/outputs/pico-haptics-bridge-v043/`：当前v043固件源码；旧版本保留用于对照。
- `docs/`：当前状态、接续、研究、历史证据；按索引阅读。
- `build/`：本机忽略的工具链与可再生成产物，不上传。

Mac可先运行纯数据检查，不连接设备：

```sh
python3 tools/run_offline_checks.py
```

Windows硬件入口依赖HIDAPI、XInput、计时器、网络及私密安装记录，尚未完整移植到Mac。查阅入口不代表自动启动硬件会话。设备最后位置以实机核对为准，不把历史报告中的BOOTSEL状态当作当前插接状态。

实测报告、失败反例、冻结清单和第三方许可证均保留。真实凭据、设备备份、恢复镜像、私密基线包和含真实参数的固件不公开。本项目不修改飞智原厂持久配置。
