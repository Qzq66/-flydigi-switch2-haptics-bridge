# 八爪鱼 6 Pro → Switch 2 原生触觉桥接

在 Switch 2 真机运行原生游戏，使用飞智八爪鱼 6 Pro 操作，将主机原生触觉指令转换为八爪鱼音圈波形。

**当前状态：已完成 Mac 接收器枚举及厂商身份／状态查询；尚无桥接固件、按键流或震动输出验证。**

## 已有条件

- 已购买第三方 Pico 2W 创客板，Type-C、已焊排针。
- 商家标称 2 MB Flash、520 KB SRAM、无线功能；实际芯片与兼容性待到货核实。
- 允许有线；优先探索桥接器 USB 接主机、原装接收器连接无线八爪鱼。
- 完整 NS2 Pro／HD Rumble 2 是研究目标；一代 Pro 的 HD 震动兼容链路是中间里程碑。

## 执行顺序

1. 核实板卡、工具链、USB、Flash 与无线功能。
2. 在电脑上验证八爪鱼左右独立波形输出。
3. 让 Pico 被 Switch 2 接受并接收原生震动包。
4. 用电脑辅助完成真机输入和震动闭环。
5. 移植到独立硬件，评估 PIO USB／双 MCU。
6. 完善 NS2 Pro 初始化、震动模式和时序。

## 开发约定

- 每项硬件能力必须标注“文档描述／代码存在／实机验证”，不可混用。
- 记录板卡、手柄、接收器、主机和依赖版本；一次尽量只改变一个因素。
- 第三方代码先核对许可证，不在仓库中直接堆放下载的整个项目。
- 不提交凭据、私人信息、未经筛选的日志或未知授权的二进制文件。
- 每次结束更新进度及下一步，方便 macOS／Windows 接续。
