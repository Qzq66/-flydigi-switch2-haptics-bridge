# Classic连接诊断修正（尚未现场验证）

本轮只修改独立探针并离线编译，未枚举、加载或操作设备。旧源码已在本机 `work/private/bt-classic-before-fix-20261116/` 保留。

## 已修正

- `Authentication Requested`参数改为连接事件的连接句柄；旧版误传蓝牙地址，不能据其结果断定主动认证无效。
- HID回调先检查顶层`HCI_EVENT_HID_META`，再解析子事件；旧版直接用顶层类型匹配HID子事件，会漏掉正常事件。
- 删除所有猜测的Xbox震动报告与自动播放流程。成功时仅保存报告描述符并结束，不发送Output/Feature报告。
- 增加认证命令状态日志，取消自动再次查询；无线电轮询/清理由初始化成功标志保护。

## 验证及限制

RAM镜像编译通过。反汇编中对Flash擦写、HID Set Report/Send Report/Get Report的直接调用均为0，见 [结构化记录](campaigns/realtime-2026-11-15/bt-classic-no-output-fix-20261116.json)。这属于编译及调用检查，不代替现场全量Flash核对，也不证明蓝牙连接成功。

保留此前现场证据，不改写其报告。BLE未观察到广播不等于协议绝对不存在；ACL成功不等于HID成功。
