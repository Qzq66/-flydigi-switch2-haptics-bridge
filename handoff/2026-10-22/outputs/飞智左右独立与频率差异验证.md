# 飞智左右独立与频率差异验证

日期：2026-10-22（中国时间）

## 验收结论

- 左右独立：通过本轮主观验收。用户确认四段输出的左、右位置与预告顺序一致，分离明显。
- 频率变化：60 Hz 与 240 Hz 在同一左握把上的差异，经用户确认明显。
- 80 Hz 与 160 Hz：用户先后表示有些差异但不确定，不能据此标为明显可辨。
- 正常停止：本轮三个输出会话均完成中性帧、通道关闭、整组实时路由关闭，收到成功 ACK。
- 配置保留：每轮四类配置均与各自测试前备份逐字节一致；未发送保存、升级、重置或切换配置槽命令。

这些结果是传输记录和用户触觉反馈，不是用加速度计测得的实际机械频谱、幅度线性或保真度证明。

## 测试条件

当前八爪鱼设备类型 0x96，VID/PID 37D7:2502，使用 FFA0/MI02、33 字节 HID 报告接口。Pico 保持拔出，避免重现外接键鼠受影响的问题。物理连接方式以用户所述接收器为背景；设备信息中的 connection_mode=1 与参考解释存在冲突，未据此断定连接形态。

握把样本以 128 为中性值，偏移最大 ±5，约为数字满量程的 3.9%；这不是马达实测幅度或厂商界面强度百分比。所有扳机样本始终为中性值。编码按每包 8 个样本、名义每 8 ms 一包发送。轮间输出中性样本，未增加强度。

## 配置与退出保护

- 播放前重新备份全局 RAM 1、活动槽映射 RAM 4、灯光 RAM 5、马达 RAM 6，校验每块 CRC32，并读回本地备份文件。
- 核对设备身份摘要及已验证马达配置指纹，不匹配时拒绝播放。
- 仅临时设置整组握把实时路由，不使用已被拒绝的逐侧恢复参数。
- 结束后发送中性帧、通道关闭，等待80 ms，再执行整组关闭；仅超时/传输错误可有界重试，最多3次。
- 三轮输出会话中，关闭确认均在第一次尝试成功。当前四类配置指纹与测试前一致；未对所有存储区或工厂校准区作全盘证明。
- 备份只涵盖全局和活动槽，不能视为完整原厂镜像或全部配置槽备份。
